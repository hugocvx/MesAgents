# Veille AAC

Veilles d’appels à publications / communications.

## Études ibériques

- Fichiers Markdown : `etudes-iberiques/YYYY-MM-DD.md`
- Versions HTML (consultation navigateur) : `etudes-iberiques/YYYY-MM-DD.html` et `etudes-iberiques/index.html`

## Rendre les pages HTML publiques (lien libre)

Le dépôt est actuellement **privé** : les fichiers HTML dans Git ne sont **pas** accessibles anonymement.

Pour un lien public du type « quiconque a l’URL peut ouvrir la page » :

1. Dans GitHub → **Settings** → **Pages**
2. Source : Deploy from a branch
3. Branch : `main` (après merge) ou la branche de veille ; dossier `/veille-aac` ou `/` selon votre choix
4. Envisager de rendre le dépôt **public**, ou d’activer Pages en mode public si votre plan GitHub le permet

URL attendue après activation (exemple) :

`https://hugocvx.github.io/MesAgents/etudes-iberiques/`

(ou `…/veille-aac/etudes-iberiques/` selon le dossier racine Pages choisi)
